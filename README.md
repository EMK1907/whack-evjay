# LOOP by whack-evjay

### What the project does?
This is an adventure/ puzzle game that allows the player to explore different worlds. The objective for the user is to get back to real world but everytime he escapes a world he gets stuck in another world and this continues in a loop. 

### How users can get started with the project?
There are instructions for how to play on the menu screen. There is something about each world that differs from the norm. Find it and escape. 

## Future changes?
The creation of many more worlds. Each world would get A/B tested for retention and only the best worlds would be used. This would string together many short fun worlds for the user to discover.
